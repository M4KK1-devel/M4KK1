# 第 3 章 基础使用

## 3.1 M4SH Shell

M4SH 是系统的 init 进程（PID 1），提供交互式命令行环境。

### 提示符

```
[m4kk1]@m4sh ~>
```

- `[m4kk1]` — 黄色显示
- `m4sh` — 青色显示
- 有效命令显示绿色，无效命令显示红色

### 命令行编辑

| 按键 | 功能 |
|------|------|
| 字符键 | 追加到命令行 |
| Backspace / 0x7F | 删除最后一个字符 |
| Enter | 执行命令 |
| Tab | 命令名补全 |
| ↑ | 历史上一条 |
| ↓ | 历史下一条 |
| Ctrl+C | 取消当前行 |
| Ctrl+D | 空行时退出 Shell |

### 命令历史

最多 16 条记录，连续重复不计入。

## 3.2 文件和目录操作

| 命令 | 功能 |
|------|------|
| `ls [路径]` | 列出目录内容 |
| `cat <文件>` | 显示文件内容 |
| `cd <目录>` | 切换工作目录 |
| `pwd` | 显示当前目录 |

## 3.3 文本处理

| 命令 | 功能 |
|------|------|
| `echo [参数]` | 输出文本（支持 `\n` `\t` 等转义） |
| `grep <模式> [文件]` | 正则搜索文本 |
| `wc [文件]` | 统计行/词/字符数 |
| `diff <文件1> <文件2>` | 比较文件差异 |
| `sead <脚本> [文件]` | 流编辑器 |

## 3.4 引号处理

M4SH 支持三种引号模式：

- **单引号 `'...'`**: 逐字保留内容，不展开变量
- **双引号 `"..."`**: 保留内容，支持 `\"` `\\` `\$` 转义
- **反斜杠 `\`**: 转义下一个字符

### 示例

```bash
echo 'hello $PATH'    # 输出: hello $PATH
echo "hello $PATH"    # 输出: hello /bin:/usr/bin
echo hello\ world     # 输出: hello world
```

## 3.5 命令操作符

| 操作符 | 功能 |
|--------|------|
| `;` | 顺序执行 |
| `&&` | 前一命令成功则执行后一命令 |
| `||` | 前一命令失败则执行后一命令 |
| `|` | 管道（前一命令输出作为后一命令输入） |

### 示例

```bash
echo hello ; echo world      # 两个命令都执行
echo ok && echo also          # 都执行
false || echo fallback        # 只执行 fallback
echo hello | grep h           # 管道
```

## 3.6 环境变量

最多 16 个变量，每个最大 128 字节。

```bash
export PATH=/bin:/usr/bin
echo $PATH              # 展开变量
echo '${PATH}'          # 字面输出
```

## 3.8 文件系统层次

```
/
├── bin/          # 可执行文件 (login, m4sh)
├── dev/          # 设备文件
├── export/
│   ├── cfg/      # 配置文件 (passwd.db, groups.db)
│   ├── home/     # 用户家目录
│   └── root/     # root 家目录
├── etc/          # 系统配置
├── mnt/          # 挂载点
├── sys/
│   ├── proc/     # 进程伪文件系统
│   └── sessions/ # 会话管理
├── tmp/          # 临时文件
└── usr/          # 用户程序
```
