# 第 1 章 引言

## 1.1 关于 M4KK1

M4KK1 是一个从零开发的 i386 操作系统，采用 **4P1 独立标准**，不兼容 POSIX。项目使用 freestanding C 和 NASM 汇编编写，遵循宏内核设计。

### 设计哲学

- **清晰优于兼容**: 不背负 POSIX 历史包袱，接口设计追求可读性和可预测性
- **简洁优于臃肿**: 接口数量少，行为确定，易于理解和实现
- **原生优于模拟**: 所有工具和库基于原生 M4KK1 ABI，无兼容层

## 1.2 核心特性

| 特性 | 说明 |
|------|------|
| 内核 | Y4KU 宏内核，i386 保护模式，GRUB multiboot 引导 |
| 内存 | 平坦 32 位物理内存，无 MMU/分页（设计特性，非缺陷） |
| 系统调用 | `int 0x80`（兼容）+ `int 0x4D`（原生，`0x4D00XXXX` 格式） |
| 文件系统 | YAFS — 基于 COW B+Tree 的 RAM 磁盘（16 MB） |
| 用户空间 | M4SH 单进程 Shell，40+ 内置命令，静态链接 |
| 控制台 | 串口 COM1，38400 8N1 |
| 错误处理 | 不兼容 `errno`，函数直接返回负值表示错误 |

## 1.3 命名约定

| 前缀 | 范围 | 示例 |
|------|------|------|
| `mkrn_` | 内核全局函数/变量 | `mkrn_timer_init()` |
| `musr_` | 用户空间全局函数/变量 | `musr_cmd_echo()` |
| `m4k_` | 系统调用 ABI 层 | `m4k_spawn()` |
| 无前缀 | 文件内静态 | `tokenize_quoted()` |

## 1.4 系统架构

```
┌────────────────────────────────────┐
│         用户空间 (Ring 0)          │
│  ┌──────────────────────────────┐  │
│  │  M4SH Shell (PID 1)         │  │
│  │  40+ 内置命令 / 正则引擎     │  │
│  └──────────┬───────────────────┘  │
├─────────────┼──────────────────────┤
│         系统调用层                  │
│  int 0x80 / int 0x4D              │
├─────────────┼──────────────────────┤
│         内核空间                    │
│  进程管理 | 文件系统 | 内存 | 驱动 │
│  架构层: GDT / IDT / PIT / RTC    │
└────────────────────────────────────┘
```

## 1.5 启动流程

```
GRUB → entry.asm → kmain()
  ├── 内存初始化 → GDT → IDT → PIT (1000 Hz)
  ├── 进程管理 → 系统调用 → VFS → YAFS
  ├── 写入 ELF (m4sh / login) → 创建配置文件
  └── exec init → login → m4sh
```

## 1.6 项目状态

当前为 **v1.0.0-alpha1**，处于早期实验阶段。已完成内核基础、YAFS 文件系统、M4SH Shell 和 40+ 内置命令。

### 已知限制

- i386 32-bit 仅，无 SMP/APIC
- 单进程用户空间，全部 Ring 0
- 无 MMU 隔离、无网络栈、无图形界面
- YAFS 无日志/崩溃恢复
- 无 POSIX 兼容层
